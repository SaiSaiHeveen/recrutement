Générateur de hash

Calcule le hash SHA-256 d'un nouveau mot de passe admin. Le calcul se fait uniquement dans ton navigateur, rien n'est envoyé.

1. Colle ce hash dans config.js → ADMIN_PASSWORD_HASH
2. Exécute cette requête dans Supabase → SQL Editor
3. Enregistre config.js, puis publie le changement (Commit + Push dans GitHub Desktop). Reconnecte-toi avec le nouveau mot de passe.
